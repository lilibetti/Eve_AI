回顾

你们这一周做了什么

周一：你打开了第一个 AI 工具，跟它说了三句话。

周二到周五：你描述了一个东西、看 AI 给你什么、把它跑起来、截了第一张屏、发了到群里互看。

你手上现在有一个能跑的东西。可能很简陋——一个页面、一个按钮、一段看不懂的代码——但它是真的。

你已经在「看见」了。
今天我们要把这张地图展开，让你知道接下来往哪走。
工具箱

你已经认识了三样工具

这一周你打开工具箱，看到了三样东西：

前端
用户能看到的东西。
页面、按钮、输入框、图片。
后端
用户看不见的东西。
处理数据、跑逻辑、算结果。
数据库
数据存的地方。
关了再打开，东西还在。
🏗 CS 硬核 🔬 AI 前沿

这就是计算机的工具箱。接下来一个月你不需要学更多类别——只需要让这三样东西在你脑子里越来越清晰。

而你的 AI 工具箱长这样：

ChatGPT
通用对话。写代码、解释概念、帮你理思路。
Claude Code
终端里的 AI 程序员。能直接改你的项目文件。
Cursor
AI 加持的编辑器。代码补全、对话、一键修改。

不用现在就学会。这是让你看一眼——你知道它们存在就够了。后面几周会一个个打开。

路径

从工具箱到路径

知道了工具有什么，下一步是什么？

很多人告诉你——软件要按前后端分工来做。前端一个人、后端一个人、数据库一个人。三个人同时开工。

但你只有一个人。一个人不需要把活分给三个人。一个人需要知道先做哪块、再做哪块、做到哪一步算「这一块可以了，进下一块」。

不要按分工拆。
按依赖顺序拆。

分工是空间上的切分——谁做什么。依赖是时间上的切分——先做什么、后做什么。这是两种完全不同的思维方式。

第一块

让它能看见

01
界面出现在屏幕上

不管你的软件是什么——小程序、网页、App——第一件事是让界面出现在屏幕上。一个输入框、一个按钮、一个能显示数据的地方。

不需要好看，不需要完整，但必须能看见。因为你和 AI 的协作需要一个可视化的锚点——你对着空气描述「我想要一个管理系统」，AI 给你代码，你看不懂，也不知道跑起来什么样。但如果它先给你一个在浏览器里能打开的页面——哪怕只有一行标题——你的伪代码就找到了第一个实物。

你能说：「好，现在在这个页面里加一个输入框。」

🏗 HTML / CSS 🔬 AI 工具 → 代码 → 屏幕
🎬 现场演示
打开 ChatGPT。输入：「帮我写一个 HTML 页面，上面有一个标题「我的第一个软件」和一个按钮。」
复制代码 → 保存为 .html → 浏览器打开。
30 秒。从一句话到一个能看的页面。
第二块

让它能记住

02
数据存得住

你有了界面。用户填了数据，点保存——数据去哪了？刷新页面，数据还在吗？

这是状态。软件和一张图片的区别是：软件有记忆。用户做了什么，软件要记住。

新手最容易卡死在这一步——因为这一块需要你去碰那些藏在表面下面的东西：数据存在哪、怎么拿回来、为什么刷新就没了。

🏗 变量 → 数据结构 → 存本地 → 存云端 🔬 AI 怎么帮你管状态

这一块你需要认识三个东西——用生活比喻，不用术语：

变量
一段有名字的内存。
像贴了标签的抽屉。
「用户名 = 张三」→ 抽屉标签叫「用户名」，里面放的是「张三」。
数据结构
怎么把抽屉组织起来。
列表 = 排队的篮子（第1个、第2个…）
字典 = 贴标签的抽屉组（「姓名:张三, 年龄:22」）
数据库
在云端不会消失的抽屉柜。
关了电脑、关了浏览器——数据还在。
数据库说的语言叫 SQL，长这样：
SELECT * FROM users
你不用学会写——但你要知道它在说什么。

顺序不能颠倒：先在自己电脑上跑通「存一个东西，关了再打开它还在」→ 再去想「别人也能用」这件事。

第三块

让它能出去

03
别人也能用了

你的软件在自己电脑上跑得好好的——现在怎么让别人也能用？这就是部署。

一个人用 AI 做部署，不需要学微服务和 CI/CD。你只需要知道三件事：

服务器
一台永远开着的电脑。
你的代码跑在上面，
别人随时能访问。
域名
别人找到这台电脑的地址。
就像电话号码 vs 通讯录名字——
IP 是号码，域名是名字。
HTTP
你跟远方电脑说话的方式。
你在浏览器输入一个网址，
本质上在说：
「请把那个页面给我。」
🏗 服务器 / 域名 / HTTP 🔬 GitHub Pages / Vercel 一键部署

AI 能帮你做部署的 95%。剩下 5% 是你必须自己判断的——比如：你的项目是网页还是小程序？你需要的是 GitHub Pages 还是微信开发者工具？AI 不会替你选，但它会帮你做完你选的路。

核心

用顺序替代复杂度

①
看见
界面出来了吗？
②
记住
数据存住了吗？
③
出去
别人能打开吗？

三块，每一块都能独立验证。不需要等全部做完才知道「对不对」。

这就是一个人用 AI 做软件的核心方法——不是把一个复杂问题切成小块，是把三个有先后顺序的问题串起来。走到哪一步，你都知道自己在哪。

你不需要学完所有东西才能开始。
你只需要知道——
先在屏幕上看见，再存住，再拿出去。
